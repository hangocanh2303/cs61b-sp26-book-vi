# 37.1 Giới Thiệu Về Nén Dữ Liệu

Để làm quen với nén dữ liệu, hãy xem qua quá trình tạo và giải nén một file zip.

<pre class="language-bash"><code class="lang-bash">$ zip mobydick.zip mobydick.txt 
adding: mobydick.txt (deflated 59%)

$ ls -l
<strong>-rw-rw-r-- 1 jug jug 643207 Apr 24 10:55 mobydick.txt
</strong>-rw-rw-r-- 1 jug jug 261375 Apr 24 10:55 mobydick.zip
</code></pre>

Chú ý rằng kích thước file đã thay đổi sau khi nén!

## Mô Hình Nén 1: Thuật Toán Trên Bit

Trong mô hình nén đầu tiên, ta xem việc nén như áp dụng một _thuật toán nén_ lên chuỗi bit. Để đảo ngược quá trình, ta áp dụng _thuật toán giải nén_.

<figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption><p>Nén và giải nén.</p></figcaption></figure>

Giả sử bạn có file văn bản `example.txt`. Khi nén, bạn được `example.zip` — một file zip nhỏ hơn nhiều so với file gốc. Đây chính là ý tưởng cốt lõi của nén dữ liệu: giảm kích thước file.

Khi giải nén `example.zip` thành `unzippedexample.txt`, bạn sẽ không thấy khác biệt gì so với `example.txt` ban đầu. Đây là đặc điểm của nén **không mất mát** (lossless) — không có thông tin nào bị mất.
