# 37.1 Giới Thiệu Về Nén Dữ Liệu



Để giới thiệu về nén dữ liệu, hãy xem xét quá trình tạo và giải nén một file zip.

<pre class="language-bash"><code class="lang-bash">$ zip mobydick.zip mobydick.txt 
adding: mobydick.txt (deflated 59%)

$ ls -l
<strong>-rw-rw-r-- 1 jug jug 643207 Apr 24 10:55 mobydick.txt
</strong>-rw-rw-r-- 1 jug jug 261375 Apr 24 10:55 mobydick.zip
</code></pre>

Lưu ý rằng trước và sau khi giải nén, kích thước file thay đổi!

## Mô Hình Nén 1: Thuật Toán Trên Bit

Trong mô hình nén đầu tiên, ta xem nén dữ liệu như việc áp dụng một _thuật toán nén_ lên một chuỗi bit. Để đảo ngược quá trình nén, ta áp dụng _thuật toán giải nén_ ngược lại.

<figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption><p>Nén và giải nén.</p></figcaption></figure>

Giả sử bạn có một file văn bản tên `example.txt`. Nếu bạn nén file văn bản đó, bạn sẽ được `example.zip`, một file zip có kích thước nhỏ hơn nhiều so với file `example.txt` ban đầu. Đây là ý tưởng chính đằng sau nén dữ liệu — một kỹ thuật được sử dụng để giảm kích thước file.

Sau đó, nếu bạn giải nén `example.zip` thành một file tên `unzippedexample.txt`, bạn sẽ không nhận thấy sự khác biệt nào giữa `example.txt` và `unzippedexample.txt`. Đây là dấu hiệu của nén **không mất mát** (lossless), trong đó không có thông tin nào bị mất.
