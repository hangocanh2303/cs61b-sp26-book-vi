# 37.8 Bài Tập

## Thực Tế (Factual)

1. Giả sử ta xây dựng mã Shannon-Fano hoặc Huffman cho văn bản câu hỏi này (gồm khoảng trắng và dấu câu). Ký tự nào sẽ có mã dài nhất?
2. Có hai cách nào để biểu diễn mã Huffman cho ký tự trong Java?

<details>

<summary>Bài 1</summary>

`?` và `.`, vì cả hai chỉ xuất hiện một lần trong câu trên.

</details>

<details>

<summary>Bài 2</summary>

Một `HashMap<Character, BitSequence>` hoặc một `BitSequence[]`. Hai cách này tương đương trong Java vì Character thực chất là một số.

</details>

## Thủ Tục (Procedural)

1. Giả sử ta có chuỗi `abcdefg` lặp lại 1000 lần. Dòng bit nén sẽ có bao nhiêu bit?

<details>

<summary>Bài 1</summary>

Vì cả 8 ký tự có tần suất bằng nhau, mã hóa Huffman cho cây nhị phân cân bằng, nên mọi từ mã đều dài 3 bit. 1000 × 8 × 3 = 24000 bit.

</details>

## Siêu Nhận Thức (Metacognitive)

1. Dùng ý tưởng bit tự giải nén, hãy đưa ra cách mã hóa cho chuỗi `abdefg` lặp lại 1000 lần sao cho dùng ít hơn 2000 bit.&#x20;

<details>

<summary>Bài 1</summary>

Ý tưởng bit tự giải nén bao gồm viết code tạo ra chuỗi gốc. Có thể thực hiện bằng code sau:

```java
public class Sequence {
    public static void main(String[] args) {
        for (int i = 0; i < 1000; i++) {
            for (int j = 0; j < 8; j++) {
                System.out.print(String.format("%c", 'a' + j));
            }
        }
    }
}
```

Code này dùng đúng 239 ký tự, tức 1912 bit. Điều này cho thấy sức mạnh của mô hình bit tự giải nén: so sánh với 24000 bit cần cho mã Huffman.

</details>
