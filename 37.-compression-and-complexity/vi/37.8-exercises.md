# 37.8 Bài Tập

## Thực Tế (Factual)

1. Giả sử ta xây dựng mã Shannon-Fano hoặc Huffman cho văn bản của câu hỏi này bao gồm khoảng trắng và ký tự dấu câu. Ký tự nào sẽ có mã dài nhất?
2. Hai cách nào có thể biểu diễn mã Huffman cho các ký tự trong Java?

<details>

<summary>Bài 1</summary>

`?` và `.`, vì cả hai chỉ được sử dụng một lần trong câu trên.

</details>

<details>

<summary>Bài 2</summary>

Một `HashMap<Character, BitSequence>` hoặc một `BitSequence[]`. Lưu ý rằng hai cách này tương đương trong Java vì một Character chính là một số.

</details>

## Thủ Tục (Procedural)

1. Giả sử ta có chuỗi `abcdefg` lặp lại 1000 lần. Bao nhiêu bit sẽ có trong dòng bit đã nén?

<details>

<summary>Bài 1</summary>

Vì tất cả 8 ký tự có tần suất bằng nhau, ta được cây nhị phân cân bằng làm mã hóa Huffman, nên tất cả từ mã đều dài 3 bit. 1000 \* 8 \* 3 = 24000 bit.

</details>

## Siêu Nhận Thức (Metacognitive)

1. Sử dụng ý tưởng bit tự giải nén, hãy đưa ra một mã hóa cho chuỗi `abdefg` lặp lại 1000 lần sử dụng ít hơn 2000 bit.&#x20;

<details>

<summary>Bài 1</summary>

Ý tưởng bit tự giải nén bao gồm viết code hoặc trình thông dịch có thể tạo ra chuỗi gốc chưa nén. Điều này có thể thực hiện bằng code sau:

```java
public class Sequence {
    public static void main(String[] args) {
        for (int i = 0; i < 1000; i++) {
            for (int j = 0; j < 8; j++) {
                System.out.print(String.format("%c", 'a' + j));
            }
        }
    }
}
```

Code này sử dụng chính xác 239 ký tự, hay 1912 bit. Điều này chứng minh sức mạnh của mô hình bit tự giải nén: so sánh với 24000 bit cần thiết cho mã Huffman.

</details>
