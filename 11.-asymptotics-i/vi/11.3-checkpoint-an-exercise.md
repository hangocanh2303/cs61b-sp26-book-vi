# 11.3 Checkpoint: một bài tập

Bài tập: Áp dụng kỹ thuật 2A và 2B cho `dup2`.

* Tính số lần thực hiện từng thao tác trong đoạn mã sau, biểu diễn theo `N`.
* Dự đoán _**thứ bậc / cỡ độ lớn (rough)**_ của từng số đếm.

```java
for (int i = 0; i < A.length - 1; i += 1){
  if (A[i] == A[i + 1]) { 
    return true; 
  }
}
return false;
```

#### Lời giải:

Lưu ý: Sai lệch một chút cũng không sao — như đã nói, ta chỉ cần ước lượng _**gần đúng (rough)**_.

| Thao tác       | Số đếm theo ký hiệu | Số lần (với N=10000) |
| -------------- | -------------- | ------------------- |
| i = 0          | 1              | 1                   |
| j = i+1        | 0 đến $$N$$     | 0 đến 10,000         |
| <              | 0 đến $$N-1$$   | 0 đến 9,999          |
| ==             | 1 đến $$N-1$$   | 1 đến 9,999          |
| truy cập mảng | 2 đến $$2N-2$$  | 2 đến 19998          |

Hãy so sánh bảng của `dup1` với bảng của `dup2`:

Bảng `dup1`:

| Thao tác       | Số đếm theo ký hiệu         | Số lần (với N=10000)                               |
| -------------- | ------------------------ | ------------------------------------------------- |
| i = 0          | 1                        | 1                                                 |
| j = i+1        | 1 đến $$N$$               | 1 (trường hợp tốt nhất) đến 10000 (trường hợp xấu nhất) |
| <              | 2 đến $$(N² + 3N + 2)/2$$ | 2 đến 50,015,001                                   |
| += 1           | 0 đến $$(N² + N)/2$$      | 0 đến 50,005,000                                   |
| ==             | 1 đến $$(N² - N)/2$$      | 1 đến 49,995,000                                   |
| truy cập mảng | 2 đến $$N²-N$$            | 2 đến 99,990,000                                   |

Bảng `dup2`:

| Thao tác       | Số đếm theo ký hiệu | Số lần (với N=10000) |
| -------------- | -------------- | ------------------- |
| i = 0          | 1              | 1                   |
| j = i+1        | 0 đến $$N$$     | 0 đến 10,000         |
| <              | 0 đến $$N-1$$   | 0 đến 9,999          |
| ==             | 1 đến $$N-1$$   | 1 đến 9,999          |
| truy cập mảng | 2 đến $$2N-2$$  | 2 đến 19998          |

Ta thấy `dup2` trong trường hợp xấu nhất hiệu quả hơn `dup1` rất nhiều!&#x20;

Một cách lý giải là `dup2` cần ít phép toán hơn để đạt cùng mục tiêu với `dup1`.&#x20;

Một nhận thức sâu hơn: trong trường hợp xấu nhất, `dup2` **hiệu quả hơn rất nhiều** so với `dup1` (ví dụ số phép `<` cỡ $$(N^2 + 3N + 2)/2$$ so với cỡ $$N$$).

Một nhận thức **sâu hơn nữa**: parabol ($$N^2$$) luôn tăng nhanh hơn đường thẳng ($$N$$) khi $$N$$ đủ lớn.
