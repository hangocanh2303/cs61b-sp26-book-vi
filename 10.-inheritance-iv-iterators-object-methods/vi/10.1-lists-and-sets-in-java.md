### List trong mã Java thực tế

Ta đã xây danh sách từ đầu, nhưng Java cung cấp giao diện `List` và nhiều lớp triển khai, chẳng hạn `ArrayList`. Nhớ rằng `List` là giao diện nên không thể `new List()` — phải khởi tạo một lớp triển khai cụ thể.

Để dùng, ta có thể viết tên đầy đủ (“tên chuẩn”) của lớp/giao diện:

```java
java.util.List<Integer> L = new java.util.ArrayList<>();
```

Cách này hơi dài. Thay vào đó, ta có thể `import` thư viện của Java:

```java
import java.util.List;
import java.util.ArrayList;

public class Example {
    public static void main(String[] args) {
        List<Integer> L = new ArrayList<>();
        L.add(5);
        L.add(10);
        System.out.println(L);
    }
}
```

### Set

Set là tập các phần tử **không trùng** — mỗi phần tử chỉ xuất hiện một lần. Khác với list, set cũng **không** có thứ tự truy cập theo chỉ số: không lấy phần tử bằng index, và cũng không kiểm soát được “vị trí chèn” của từng phần tử.

#### Set trong Java

Java có giao diện `Set` và các lớp triển khai, ví dụ `HashSet`. Nhớ `import` nếu không muốn viết tên đầy đủ mỗi lần.

```java
import java.util.Set;
import java.util.HashSet;
```

Ví dụ:

```java
Set<String> s = new HashSet<>();
s.add("Tokyo");
s.add("Lagos");
System.out.println(s.contains("Tokyo")); // true
```

#### Tương đương trong Python

Trong Python, ta dùng `set()`. Để kiểm tra thành viên, ta dùng toán tử `in` thay vì gọi một phương thức kiểu `contains`. Ví dụ:

```python
s = set()
s.add("Tokyo")
s.add("Lagos")
print("Tokyo" in s) // True
```

### Tự làm: ArraySet

Mục tiêu là tự viết một set, `ArraySet`, với các phương thức:

* `add(value)`: thêm giá trị vào set nếu chưa có
* `contains(value)`: kiểm tra `ArraySet` có chứa giá trị đó không
* `size()`: trả về số phần tử
