# 10.5 Tóm tắt chương

Mã nguồn của bài giảng này nằm [tại đây](https://github.com/Berkeley-CS61B/lectureCode-sp23/tree/main/lec12_inheritance4).&#x20;

### Exceptions

Bạn có lẽ đã từng gặp ngoại lệ trong mã, chẳng hạn `NullPointerException` hay `IndexOutOfBoundsException`. Giờ ta học cách **tự ném** ngoại lệ. Ví dụ:

```
throw new RuntimeException("For no reason.");
```

Cơ chế này giúp mã xử lý hợp lý ngay cả khi gặp hành vi không lường trước được.

### Phép lặp (iteration)

#### Khác nhau giữa Iterator và Iterable

Hai từ này gần gũi nhưng **khác nghĩa**, dễ nhầm. Cả hai đều là **giao diện** trong Java, mỗi giao diện yêu cầu triển khai một tập phương thức. Dưới đây là giao diện `Iterator` (rút gọn):

```
public interface Iterator<T> {
  boolean hasNext();
  T next();
}
```

Và giao diện `Iterable` (rút gọn):

```
public interface Iterable<T> {
    Iterator<T> iterator();
}
```

Chú ý: để một đối tượng (ví dụ `ArrayList` hay `LinkedList`) có thể dùng trong vòng lặp for-each — tức là **iterable** — nó phải có phương thức trả về một **iterator**. Iterator là đối tượng **chủ động bước** qua cấu trúc iterable. Giữ mối quan hệ và sự khác biệt này khi làm việc với hai giao diện.

### Các phương thức của Object

#### toString

`toString()` trả về biểu diễn dạng chuỗi của đối tượng. Ví dụ, `System.out.println(someObject)` gọi `toString()` của `someObject` rồi in chuỗi đó ra console.&#x20;

Rất hữu ích khi gỡ lỗi, vì giúp đọc **trạng thái** của đối tượng dễ hơn nhiều.

#### == so với .equals

Trong Java có hai khái niệm “bằng nhau”: toán tử `==` và phương thức `.equals()`. Khác biệt cốt lõi: `==` kiểm tra hai tham chiếu có **cùng địa chỉ bộ nhớ** (cùng một thể hiện) hay không; còn `.equals()` có thể bị ghi đè để định nghĩa tiêu chí bằng nhau **theo ngữ nghĩa**, dựa trên kiến thức nội tại của lớp.

Ví dụ, muốn kiểm tra hai “hòn đá” có bằng nhau:

```
public class Stone{
  int weight;
  public Stone(int weight){
    this.weight = weight;
  }
}
Stone s = new Stone(100);
Stone r = new Stone(100);
```

Nếu coi `s` và `r` bằng nhau vì cùng trọng lượng, dùng `==` sẽ **không** đúng — hai đối tượng khác địa chỉ.

Nếu ghi đè `equals` như sau:

```
public boolean equals(Object o){
  return this.weight == ((Stone) o).weight
}
```

thì theo tiêu chí trọng lượng, hai hòn đá được coi là bằng nhau.
