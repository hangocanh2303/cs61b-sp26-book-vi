<details>

<summary>Bài 2</summary>

* **Nếu ta thêm các đối tượng `String[][]` vào một `Set` và một `List`, kích thước của set luôn nhỏ hơn hoặc bằng kích thước của list.** Set chỉ chứa phần tử duy nhất, còn list cho phép trùng; nếu thêm cùng các phần tử vào cả hai, số phần tử của list luôn ít nhất bằng số phần tử của set.
* **Lớp `java.util.ArrayList` là một triển khai của giao diện `java.util.List`.** `ArrayList` là một trong các lớp triển khai `List` trong Java.
* **Hai giao diện `Set` và `List` mở rộng giao diện `Iterable`.** `Set` và `List` trong Java dùng được trong vòng lặp for-each, nghĩa là chúng là `Iterable`.

</details>

## Metacognitive (tư duy về tư duy)

1. Trong bài giảng, ta đã xây lớp `ArraySetIterator`. Hãy sửa lớp trong bài giảng để hàm tạo nhận thêm một `Comparator<T>` và một tham chiếu kiểu generic `T` tên `ref`. Iterator mới chỉ trả về các phần tử **lớn hơn** `ref` (theo `Comparator`). Để tham khảo, mã `ArraySetIterator` gốc như sau.

```java
private class ArraySetIterator implements Iterator<T> {
	private int pos;
	
	public ArraySetIterator() { 
		pos = 0; 
	}
	
	public boolean hasNext() { 
		return pos < size; 
	}
	
	public T next() {
	 	T returnItem = items[pos];
	 	pos += 1;
	 	return returnItem;
	}
}
```

```java
public class ArraySetGreaterIterator implements Iterator<T> {
    private int pos;
    private T ref;
        
    private Comparator<T> comp;

    public ArraySetGreaterIterator(T ref, Comparator<T> comp) {
        this.ref = ref;
        this.comp = comp;
    }

    @Override
    public boolean hasNext() {
        return pos < size;
    }

    @Override
    public T next() {
        T returnItem = items[pos];
        while (comp.compare(returnItem, ref) <= 0) {
            pos += 1;
            returnItem = items[pos];
        }
        return returnItem;
    }
}
```
