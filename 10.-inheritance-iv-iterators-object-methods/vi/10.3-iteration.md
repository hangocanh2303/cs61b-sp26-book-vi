# 10.3 Phép lặp (iteration)

{% embed url="https://www.youtube.com/watch?v=Gv6LjusNBU0" %}

Ta có thể dùng vòng lặp for-each (enhanced for) gọn gàng với `HashSet` của Java:

```java
Set<String> s = new HashSet<>();
s.add("Tokyo");
s.add("Lagos");
for (String city : s) {
    System.out.println(city);
}
```

Nhưng nếu làm tương tự với `ArraySet` của ta thì sẽ lỗi. Làm sao để có chức năng này?

## Vòng lặp for-each <a href="#enhanced-for-loop" id="enhanced-for-loop"></a>

Trước hết, hãy hiểu điều gì xảy ra khi dùng vòng lặp for-each. Ta có thể “dịch” for-each sang một phiên bản thủ công, kém gọn hơn.

```java
Set<String> s = new HashSet<>();
...
for (String city : s) {
    ...
}
```

Đoạn trên tương đương với:

```java
Set<String> s = new HashSet<>();
...
Iterator<String> seer = s.iterator();
while (seer.hasNext()) {
    String city = seer.next();
    ...
}
```

Bóc bỏ lớp “ma thuật” để ta có thể tự xây các lớp hỗ trợ cơ chế này.

Trọng tâm là một đối tượng gọi là _iterator_.

Ví dụ: trong `List.java` ta có thể khai báo phương thức `iterator()` trả về một đối tượng iterator.

```java
public Iterator<E> iterator();
```

Sau đó, dùng đối tượng đó để duyệt qua mọi phần tử trong list:

```java
List<Integer> friends = new ArrayList<Integer>();
...
Iterator<Integer> seer = friends.iterator();

while (seer.hasNext()) {
System.out.println(seer.next());
}
```

Hành vi này giống hệt phiên bản dùng foreach ở trên.

Trong cách tiếp cận iterator có ba ý chính:

Trước hết, lấy iterator mới với `Iterator<Integer> seer = friends.iterator();`

Tiếp theo, lặp bằng `while`: kiểm tra còn phần tử với `seer.hasNext()` — trả về `true` nếu vẫn còn phần tử chưa duyệt, `false` nếu đã hết.

Cuối cùng, `seer.next()` làm hai việc: trả về phần tử kế tiếp (ở đây ta in ra), và **tiến** iterator một bước. Nhờ vậy mỗi phần tử chỉ được xem một lần.&#x20;

## Triển khai iterator <a href="#implementing-iterators" id="implementing-iterators"></a>

Phần này nói về cách xây lớp hỗ trợ phép lặp.

Bắt đầu bằng câu hỏi: trình biên dịch cần biết gì để biên dịch thành công ví dụ sau?

```java
List<Integer> friends = new ArrayList<Integer>();
Iterator<Integer> seer = friends.iterator();

while(seer.hasNext()) {
    System.out.println(seer.next());
}
```

Xét **kiểu tĩnh** của từng đối tượng nhận lời gọi phương thức tương ứng. `friends` có kiểu `List`, trên đó gọi `iterator()`, nên ta hỏi:

* Giao diện `List` có phương thức `iterator()` không?

`seer` có kiểu `Iterator`, trên đó gọi `hasNext()` và `next()`, nên ta hỏi:

* Giao diện `Iterator` có `next` / `hasNext()` không?

Vậy ta triển khai các yêu cầu đó thế nào?

Giao diện `List` mở rộng `Iterable`, kế thừa phương thức trừu tượng `iterator()`. (Thực tế `List` mở rộng `Collection` rồi mới tới `Iterable`, nhưng khi mới bắt đầu có thể tạm nghĩ theo hướng đơn giản như vậy.)

```java
public interface Iterable<T> {
    Iterator<T> iterator();
}
```

```java
public interface List<T> extends Iterable<T>{
    ...
}
```

Tiếp theo, trình biên dịch **kiểm tra kiểu tĩnh** xem giao diện `Iterator` có khai báo `hasNext()` và `next()` hay không. Giao diện `Iterator` khai báo rõ các phương thức trừu tượng này:

```java
public interface Iterator<T> {
    boolean hasNext();
    T next();
}
```

**Nếu ai đó gọi `next` khi `hasNext` trả về `false` thì sao?**

```
Hành vi không được định nghĩa chặt. Tuy nhiên, quy ước thường gặp là ném `NoSuchElementException`. Xem [Discussion 5](https://sp19.datastructur.es/materials/discussion/disc05sol.pdf) để có ví dụ.
```

**`hasNext` có luôn được gọi trước `next` không?**

```
Không nhất thiết. Đôi khi người dùng iterator biết chính xác có bao nhiêu phần tử, nên không thể kỳ vọng họ luôn gọi `hasNext` trước `next`. Tuy nhiên, bạn luôn có thể gọi `hasNext` bên trong phương thức `next` của mình.
```

Mỗi lớp cụ thể sẽ triển khai hành vi lặp riêng cho các phương thức giao diện. Xem một ví dụ. (Muốn dựng từ đầu, hãy làm theo phần live coding trong video.)

Ta sẽ thêm khả năng duyệt các phần tử cho lớp `ArraySet`. Trước hết, viết lớp mới tên `ArraySetIterator`, lồng trong `ArraySet`:

```java
private class ArraySetIterator implements Iterator<T> {
    private int wizPos;

    public ArraySetIterator() {
        wizPos = 0;
    }

    public boolean hasNext() {
        return wizPos < size;
    }

    public T next() {
        T returnItem = items[wizPos];
        wizPos += 1;
        return returnItem;
    }
}
```

`ArraySetIterator` triển khai `Iterator<T>`, tức cung cấp `hasNext()` và `next()`, dùng chỉ số `wizPos` để theo dõi vị trí trong mảng. Với cấu trúc dữ liệu khác, hai phương thức này có thể triển khai khác.

**Bài tập suy nghĩ:** Bạn sẽ thiết kế `hasNext()` và `next()` cho danh sách liên kết thế nào?

Khi đã có đủ phương thức, có thể dùng `ArraySetIterator` để duyệt một `ArraySet`:

```java
ArraySet<Integer> aset = new ArraySet<>();
aset.add(5);
aset.add(23);
aset.add(42);

Iterator<Integer> iter = aset.iterator();

while(iter.hasNext()) {
    System.out.println(iter.next());
}
```

Ta vẫn muốn hỗ trợ vòng lặp for-each cho gọn. Vì vậy cần cho `ArraySet` triển khai giao diện `Iterable`. Phương thức cốt lõi của `Iterable` là `iterator()`, trả về một đối tượng `Iterator` cho lớp đó. Ta chỉ cần trả về một thể hiện của `ArraySetIterator` vừa viết.

```java
public Iterator<T> iterator() {
    return new ArraySetIterator();
}
```

Giờ ta có thể dùng for-each với `ArraySet`.

```java
ArraySet<Integer> aset = new ArraySet<>();
...
for (int i : aset) {
    System.out.println(i);
}
```

Ở đây ta thấy **Iterable** — giao diện khiến một lớp có thể được duyệt, và bắt buộc có phương thức `iterator()` trả về đối tượng `Iterator`. Và **Iterator** — giao diện mô tả đối tượng thực sự thực hiện việc duyệt. Có thể hình dung iterator như một “máy” gắn lên một iterable để điều phối phép lặp; iterable là đối tượng mà iterator đang duyệt qua.

Hai thành phần này cho phép bạn dùng vòng lặp for-each gọn gàng cho các lớp tự định nghĩa.

Mã `ArraySet` có hỗ trợ lặp như sau:

```java
import java.util.Iterator;

public class ArraySet<T> implements Iterable<T> {
    private T[] items;
    private int size; // the next item to be added will be at position size

    public ArraySet() {
        items = (T[]) new Object[100];
        size = 0;
    }

    /* Returns true if this map contains a mapping for the specified key.
     */
    public boolean contains(T x) {
        for (int i = 0; i < size; i += 1) {
            if (items[i].equals(x)) {
                return true;
            }
        }
        return false;
    }

    /* Associates the specified value with the specified key in this map.
       Throws an IllegalArgumentException if the key is null. */
    public void add(T x) {
        if (x == null) {
            throw new IllegalArgumentException("can't add null");
        }
        if (contains(x)) {
            return;
        }
        items[size] = x;
        size += 1;
    }

    /* Returns the number of key-value mappings in this map. */
    public int size() {
        return size;
    }

    /** returns an iterator (a.k.a. seer) into ME */
    public Iterator<T> iterator() {
        return new ArraySetIterator();
    }

    private class ArraySetIterator implements Iterator<T> {
        private int wizPos;

        public ArraySetIterator() {
            wizPos = 0;
        }

        public boolean hasNext() {
            return wizPos < size;
        }

        public T next() {
            T returnItem = items[wizPos];
            wizPos += 1;
            return returnItem;
        }
    }

    public static void main(String[] args) {
        ArraySet<Integer> aset = new ArraySet<>();
        aset.add(5);
        aset.add(23);
        aset.add(42);

        //iteration
        for (int i : aset) {
            System.out.println(i);
        }
    }

}
```
