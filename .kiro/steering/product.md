# Product Overview

CS 61B (Data Structures) textbook for UC Berkeley, Spring 2026 edition. Written as a lecture companion — not a standalone data structures textbook.

- Course: CS 61B, taught by Professor Joshua Hug
- Language: Java
- Audience: Undergraduate CS students
- Status: Under active construction; some sections may be incomplete or outdated
- Bilingual: English (primary) with Vietnamese translations
- Published via GitBook

## Content Scope

Covers Java fundamentals, OOP/inheritance, data structures (lists, trees, heaps, hash tables, tries, graphs), asymptotic analysis, sorting algorithms, software engineering principles, and compression/complexity theory. Chapters 1–27 are active; chapters 30–40 exist but are commented out of the table of contents.
