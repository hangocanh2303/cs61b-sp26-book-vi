# 14.2 Quick Find

### Danh sách các tập

Theo trực giác, ta có thể ban đầu nghĩ tới việc biểu diễn Disjoint Sets bằng một danh sách các tập, ví dụ `List<Set<Integer>>`.

Chẳng hạn, nếu ta có N = 6 phần tử và chưa thực hiện thao tác nối nào, danh sách các tập trông như: `[{0}, {1}, {2}, {3}, {4}, {5}, {6}]`. Trông ổn. Tuy nhiên, cân nhắc cách thực hiện một thao tác như `connect(5, 6)`: ta có thể phải duyệt tới N tập để tìm 5 và N tập để tìm 6. Thời gian chạy trở thành `O(N)`. Hơn nữa, nếu thử triển khai, mã sẽ khá phức tạp.

> Bài học rút ra là **quyết định thiết kế ban đầu quyết định độ phức tạp của mã và thời gian chạy.**

### Quick Find

Hãy xét cách khác dùng _một mảng số nguyên duy nhất_.

* **Chỉ số của mảng** biểu diễn các phần tử của tập.
* **Giá trị tại một chỉ số** là số hiệu tập mà phần tử đó thuộc vào.

Ví dụ, ta biểu diễn `{0, 1, 2, 4}, {3, 5}, {6}` như sau:\


<figure><img src="../../.gitbook/assets/image (72).png" alt=""><figcaption><p>Set 4: {0, 1, 2, 4} | Set 5: {3, 5} | Set 6: {6}</p></figcaption></figure>

Các chỉ số mảng (0…6) là các phần tử. Giá trị tại `id[i]` là mã định danh của tập mà phần tử `i` thuộc vào. _Giá trị mã tập cụ thể không quan trọng miễn là mọi phần tử trong cùng một tập có cùng `id`._

### **`connect(x, y)`**

Xem thao tác connect hoạt động thế nào. Hiện tại `id[2] = 4` và `id[3] = 5`. Sau khi gọi `connect(2, 3)`, mọi phần tử có id 4 và 5 phải có cùng id. Ta gán tất cả giá trị 5 tạm thời:\


<figure><img src="../../.gitbook/assets/image (102).png" alt=""><figcaption><p>Set 5: {0, 1, 2, 3, 4, 5} | Set 6: {6}</p></figcaption></figure>

**`isConnected(x, y)`**

Để kiểm tra hai phần tử có cùng tập hay không (`isConnected(x, y)`), ta chỉ cần xem `id[x] == id[y]`. Đây là thao tác thời gian hằng O(1).

\
Ta gọi triển khai này là "Quick Find" vì việc kiểm tra hai phần tử có cùng tập hay không chỉ mất thời gian hằng.

### Mã và thời gian chạy

```java
public class QuickFindDS implements DisjointSets {

    private int[] id;

    /* Θ(N) */
    public QuickFindDS(int N){
        id = new int[N];
        for (int i = 0; i < N; i++){
            id[i] = i;
        }
    }

    /* need to iterate through the array => Θ(N) */
    public void connect(int p, int q){
        int pid = id[p];
        int qid = id[q];
        for (int i = 0; i < id.length; i++){
            if (id[i] == pid){
                id[i] = qid;
            }
        }
    }

    /* Θ(1) */
    public boolean isConnected(int p, int q){
        return (id[p] == id[q]);
    }
}
```



N = số phần tử trong cấu trúc DisjointSets của ta\


| Triển khai | Hàm khởi tạo                  | `connect` | `isConnected` |
| ---------- | ----------------------------- | --------- | ------------- |
| ListOfSets | Θ(N)[¹](14.2-quick-find.md#note) | O(N)      | O(N)          |
| QuickFind  | Θ(N)                          | Θ(N)      | Θ(1)          |
