# 8.1 Vấn đề về tính tổng quát

Hãy nhớ lại hai lớp danh sách mà ta đã xây tuần trước: `SLList` và `AList`. Nếu bạn xem tài liệu của chúng, bạn sẽ thấy chúng rất giống nhau. Thực tế, mọi phương thức hỗ trợ của chúng đều giống nhau!

Giả sử ta muốn viết một lớp `WordUtils` gồm các phương thức tĩnh dùng được trên danh sách từ, trong đó có một phương thức tìm chuỗi dài nhất trong một `SLList`.

**Bài tập 4.1.1.** Hãy tự viết phương thức này. Phương thức nhận vào một `SLList` các chuỗi và trả về chuỗi dài nhất trong danh sách.

Dưới đây là phương thức ta dùng làm ví dụ.

```java
public static String longest(SLList<String> list) {
    int maxDex = 0;
    for (int i = 0; i < list.size(); i += 1) {
        String longestString = list.get(maxDex);
        String thisString = list.get(i);
        if (thisString.length() > longestString.length()) {
            maxDex = i;
        }
    }
    return list.get(maxDex);
}
```

Làm sao để phương thức này hoạt động cả với `AList`?

Thực ra ta chỉ cần đổi chữ ký của phương thức: tham số

```java
SLList<String> list
```

nên đổi thành

```java
AList<String> list
```

Giờ ta có hai phương thức trong lớp `WordUtils` với đúng cùng một tên phương thức.

```java
public static String longest(SLList<String> list)
```

và

```java
public static String longest(AList<String> list)
```

Điều này thực sự được phép trong Java! Đó là thứ gọi là _nạp chồng phương thức_ (_method overloading_). Khi bạn gọi `WordUtils.longest`, Java biết phải chạy phiên bản nào tùy theo loại tham số bạn truyền vào. Nếu bạn truyền một `AList`, nó sẽ gọi phương thức cho `AList`. Tương tự với `SLList`.

Java cho phép hai phương thức trùng tên với kiểu tham số khác nhau, nhưng nạp chồng phương thức vẫn có vài nhược điểm:

* Rất lặp lại và xấu, vì giờ bạn có hai khối mã gần như giống hệt nhau.
* Nhiều mã hơn phải bảo trì: nếu muốn sửa nhỏ phương thức `longest`, chẳng hạn sửa một lỗi, bạn phải sửa trong phương thức cho từng loại danh sách.
* Nếu ta muốn thêm các loại danh sách khác, ta sẽ phải sao chép phương thức cho mỗi lớp danh sách mới.
