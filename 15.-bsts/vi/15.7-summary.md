# 15.7 Tóm tắt

Các kiểu dữ liệu trừu tượng (ADT) được định nghĩa bằng các thao tác, không phải bằng cách cài đặt. Một số ADT hữu ích:

* Disjoint Sets, Map, Set, List.
* Java cung cấp các interface Map, Set, List cùng nhiều lớp cài đặt.

Ta đã thấy hai cách cài đặt Set (hoặc Map):

* ArraySet: thao tác $$\Theta(N)$$ trong trường hợp xấu nhất.
* BST: thao tác $$\Theta(\log N)$$ nếu cây cân bằng.

Cài đặt BST:

* Tìm và chèn tương đối trực tiếp (riêng chèn có vài chỗ cần lưu ý).
* Xóa khó hơn. Cách điển hình là **xóa Hibbard**.
