# 12.6 Bài tập

## Kiến thức nền

1. Chứng minh rằng $$\Theta(\log _{2} n) = \Theta(\log _{3} n)$$.
2. Thời gian chạy của hàm sau là gì?

```java
public static int f(int n) {
    if (n <= 1) {
        return 0;
    }
    return f(n - 1) + f(n - 1) + f(n - 1);
}
```

<details>

<summary>Bài 1</summary>

Dùng tính chất của logarit, ta có $$\log_2 n = \frac{\log n}{\log 2} = \Theta(\log n)$$. Tương tự, $$\log_3 n = \frac{\log n}{\log 3} = \Theta(\log n)$$. Vậy khi xét tiệm cận liên quan tới logarit, cơ số không quan trọng (miễn là một hằng số).

</details>

<details>

<summary>Bài 2</summary>

Đây về cơ bản là `fib` với 3 lời gọi đệ quy thay vì 2. Thời gian chạy là $$\Theta(3^n)$$.

</details>

## Vận dụng

1. Tìm thời gian chạy khi gọi `print_fib` với `n` tăng tùy ý (rất lớn).

```java
public void print_fib(int n) {
   for (int i = 0; i < n; i++) {
       System.out.println(fib(i));
   }
}

public int fib(int n){
   if (n <= 0) {
     return 0;
   } else if (n == 1) {
     return 1;
   } else {
     return fib(n-1) + fib(n-2);
   }
}
```

2. Làm lại bài trên, nhưng đổi thân vòng lặp for trong `print_fib` thành:

```java
 System.out.println(fib(n));
```

3. Tìm thời gian chạy của hàm `f` với đầu vào cỡ `n`, biết hàm `createArray` như mô tả dưới đây:

```java
public static void f(int n) {
    if (n == 1) {
        return;
    }
    f(n / 2);
    f(n / 2);
    createArray(n);
}

public int[] createArray(int Q) {
    int[] x = new int[Q];
    for (int i = 0; i < x.length; i++) {
        x[i] = i;
    }
    return x;
}
```

<details>

<summary>Bài 1</summary>

Từ bài giảng, ta biết `fib(i)` tốn khoảng $$\Theta(2^i)$$ thời gian. Vòng lặp gọi `fib(0)`, `fib(1)`, …, `fib(n-1)` (vì `i` chạy từ `0` đến `n-1`), nên tổng công việc là $$2^0 + 2^1 + ... + 2^{n-1}$$ (cấp số nhân với số hạng lớn nhất $$\Theta(2^n)$$), do đó tổng thể là $$\Theta(2^n)$$.

</details>

<details>

<summary>Bài 2</summary>

Ở đây mỗi lần lặp đều gọi `fib(n)` (cùng một đầu vào), nên tổng thời gian là `n` lần thời gian của một lần `fib(n)`, tức $$\Theta(n \cdot 2^n)$$ (thường viết gọn $$\Theta(n2^n)$$).

</details>

<details>

<summary>Bài 3</summary>

Hàm này tạo hai nhánh đệ quy có kích thước một nửa mỗi lần gọi, và mỗi nút tốn công việc tuyến tính. Như vậy mỗi mức có tổng cộng $$n$$ công việc, và vì ta chia đôi đầu vào mỗi lần nên có $$\log n$$ mức, do đó thời gian chạy là $$\Theta(n \log n)$$.

</details>

## Phản tư (metacognitive)

1. Thời gian chạy của `modified_fib` sẽ là gì? Giả sử `values` là mảng cỡ n. Nếu một phần tử trong mảng `int` chưa được khởi tạo bằng một số, nó tự động bằng 0.

```java
public void modified_fib(int n, int[] values) {
   if (n <= 1) {
     values[n] = n;
     return n;
   } else {
     int val = values[n];
     if (val == 0) {
       val = modified_fib(n-1, values) + modified_fib(n-2, values);
       values[n] = val;
     }
     return val;
   }
}  
```

<details>

<summary>Bài 1</summary>

Đây là ví dụ về quy hoạch động (dynamic programming), chủ đề được trình bày kỹ hơn ở CS170. Vì mảng `values` được chia sẻ giữa các lần gọi đệ quy, mỗi chỉ số `n` chỉ bị tính lại tối đa một lần. Mỗi lần tính `values[n]` chỉ tốn thời gian hằng (cộng hai giá trị đã lưu hoặc đọc mảng). Vậy tổng thời gian là tuyến tính: $$\Theta(n)$$.

</details>
