# 24.1.1 Nỗ lực đầu tiên: DataIndexedIntegerSet

Hãy bắt đầu bằng cách xem xét cách tiếp cận sau. Cách tiếp cận này được giới thiệu trong [Hashing Video 1](https://youtu.be/rSqSlu8sEkI).

Tạm thời, ta chỉ cố cải thiện độ phức tạp từ $\Theta(\log N)$ xuống $\Theta(1)$. Ta sẽ không lo về tính so sánh được. Thực tế, ta chỉ xét việc lưu trữ và tìm kiếm các giá trị `int`.

Đây là ý tưởng: tạo một ArrayList kiểu `boolean` có kích thước 2 tỷ. Mọi giá trị mặc định là false.

* Phương thức `add(int x)` chỉ đơn giản đặt vị trí thứ `x` trong ArrayList thành true. Thao tác này mất $\Theta(1)$ thời gian.
* Phương thức `contains(int x)` chỉ trả về giá trị tại vị trí `x` trong ArrayList là `true` hay `false`. Thao tác này cũng mất $\Theta(1)$ thời gian!

```
public class DataIndexedIntegerSet {
    private boolean[] present;

    public DataIndexedIntegerSet() {
        present = new boolean[2000000000];
    }

    public void add(int x) {
        present[i] = true;
    }

    public boolean contains(int x) {
        return present[i];
    }
}
```

Xong rồi đấy. Hết rồi.

À, chưa hẳn. Có những **vấn đề** tiềm tàng nào với cách tiếp cận này?

* Cực kỳ lãng phí. Nếu giả sử một `boolean` cần 1 byte để lưu, cách trên cần `2GB` không gian cho mỗi `new DataIndexedIntegerSet()`. Hơn nữa, người dùng có thể chỉ chèn vài phần tử...
* Ta làm gì nếu ai đó muốn chèn một `String`? Hoặc các kiểu dữ liệu khác?
  * Hãy xem tiếp ở phần sau. Tất nhiên, ta có thể muốn chèn những thứ khác, như `Dog`. Sẽ tới sớm thôi!
