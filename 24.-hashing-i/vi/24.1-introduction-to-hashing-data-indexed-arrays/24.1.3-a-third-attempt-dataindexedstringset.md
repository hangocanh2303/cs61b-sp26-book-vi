# 24.1.3 Nỗ lực thứ ba: DataIndexedStringSet

Có một định dạng ký tự gọi là **ASCII**, gán một số nguyên cho mỗi ký tự. Ở đây, ta thấy giá trị lớn nhất (tức cơ số/hệ số nhân cần dùng) là 126. Hãy dùng điều đó. Giống hệt `DataIndexedEnglishWordSet`, nhưng dùng cơ số `126`.

```
public static int asciiToInt(String s) {
    int intRep = 0;
    for (int i = 0; i < s.length(); i += 1) {           
        intRep = intRep * 126;
        intRep = intRep + s.charAt(i);
    }
    return intRep;
}
```

Nếu muốn hỗ trợ tiếng Trung thì sao? Biểu diễn lớn nhất có thể là 40959, nên ta cần dùng đó làm cơ số.&#x20;

Vậy... để lưu một từ tiếng Trung 3 ký tự, ta cần một mảng có kích thước lớn hơn **39 nghìn tỷ** (trillion)! Điều này đang trở nên không thể kiểm soát... vậy hãy xem ta có thể làm gì để cải thiện, cụ thể là dùng hashCode.
