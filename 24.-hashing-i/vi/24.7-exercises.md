# 24.7 Bài tập

## 1. Tổng hợp

(a) Đúng hay Sai: Đổi kích thước được kích hoạt nếu việc thêm một cặp khóa-giá trị khiến hệ số tải lớn hơn hoặc bằng hệ số tải tối đa đã chỉ định.

<details>

<summary>Đáp án Q1(a)</summary>

**Sai**. Đổi kích thước được kích hoạt nếu việc thêm cặp khóa-giá trị khiến hệ số tải **vượt quá** (strictly exceed) hệ số tải tối đa đã chỉ định. Đổi kích thước không được kích hoạt khi hệ số tải bằng đúng hệ số tải tối đa.

</details>

(b) Đúng hay Sai: Hàm `hashCode()` có thể có nhiều kiểu trả về khác nhau.

<details>

<summary>Đáp án Q1(b)</summary>

**Sai**. Trong Java, hàm `hashCode()` **chỉ** có thể có kiểu trả về `int` để làm giá trị băm.

</details>

## 2. hashCode()....

Để một mã băm hợp lệ, các đối tượng tương đương nhau (tức `.equals()` trả về true) phải trả về mã băm tương đương. Nếu một đối tượng không ghi đè (override) tường minh phương thức `hashCode()`, nó sẽ kế thừa `hashCode()` được định nghĩa trong lớp Object, vốn trả về địa chỉ bộ nhớ của đối tượng.

Dưới đây là bốn cách cài đặt tiềm năng cho hàm `hashCode()` của Integer. Giả sử `intValue()` trả về giá trị mà đối tượng Integer biểu diễn.&#x20;

Hãy phân loại mỗi cách cài đặt `hashCode()` là hàm băm hợp lệ hoặc không hợp lệ. Nếu hợp lệ, chỉ ra nhược điểm. Nếu không hợp lệ, giải thích tại sao.&#x20;

Câu (a)

```java
public int hashCode() {
    return -1;
}
```

<details>

<summary>Đáp án Q2(a)</summary>

Hợp lệ. Đúng theo yêu cầu, hàm băm này trả về cùng mã băm cho các Integer bằng nhau qua `.equals()`. Tuy nhiên, đây là mã băm rất tệ vì va chạm cực kỳ thường xuyên — xảy ra 100% trường hợp.

</details>

Câu (b)

```java
public int hashCode() {
    return intValue() * intValue();
}
```

<details>

<summary>Đáp án Q2(b)</summary>

Hợp lệ. Tương tự (a), hàm băm này trả về cùng mã băm cho các Integer bằng nhau qua `.equals()`. Tuy nhiên, các Integer có cùng giá trị tuyệt đối sẽ va chạm (ví dụ x = 5 và x = -5 đều trả về cùng mã băm). Hàm băm tốt hơn sẽ là trả về chính `intValue()`.

</details>

Câu (c)

```java
public int hashCode() {
    Random rand = new Random();
    return rand.nextInt();
}
```

<details>

<summary>Đáp án Q2(c)</summary>

Không hợp lệ. Nếu ta gọi `hashCode()` nhiều lần trên cùng một đối tượng Integer, ta sẽ nhận được các mã băm khác nhau mỗi lần.

</details>

Câu (d)

```java
public int hashCode() {
    return super.hashCode();
}
```

<details>

<summary>Đáp án Q2(d)</summary>

Không hợp lệ. Hàm băm này trả về một số nguyên tương ứng với vị trí bộ nhớ của đối tượng Integer. Các đối tượng Integer khác nhau sẽ tồn tại ở các vị trí bộ nhớ khác nhau, nên kể cả khi chúng biểu diễn cùng một giá trị, chúng vẫn trả về mã băm khác nhau.

</details>

## 3. Băm và đổi kích thước

Cho cách cài đặt `hashCode()` được cung cấp, hãy băm các phần tử liệt kê bên dưới với nối chuỗi ngoài (external chaining) (phần tử đầu tiên đã được chèn sẵn cho bạn). Giả sử hệ số tải là 1, và mảng nền ban đầu có kích thước 4. Dùng đổi kích thước hình học với hệ số nhân 2. Bạn có thể vẽ thêm ô để mở rộng mảng khi cần đổi kích thước.

```java
/** Returns 0 if word begins with 'a', 1 if it begins with 'b', etc. */
public int hashCode() {
    return word.charAt(0) - 'a';
}
```
