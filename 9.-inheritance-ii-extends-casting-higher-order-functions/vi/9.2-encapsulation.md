# 9.2 `Comparable` và `Comparator`

## Comparable

Lấy một ví dụ động lực, xét đoạn Java sau — ta muốn tìm con chó lớn nhất trong một danh sách các con chó.

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Dog maxDog = Collections.max(dogs);
```

Đoạn mã này trông gần được, nhưng có một vấn đề: Java không biết cách so sánh các con chó. Kết quả là một thông báo lỗi biên dịch (do kiểm tra kiểu tĩnh) khá khó hiểu, kiểu như không tồn tại thể hiện nào của (các) biến kiểu `T` sao cho `Dog` tương thích với `Comparable<? super T>`.

Khác với Python — nơi ta định nghĩa phương thức `__gt__` để cho phép so sánh — Java không có nạp chồng toán tử. Thay vào đó, ta phải dùng kế thừa theo cách triển khai (implementation inheritance). Cụ thể, ta sẽ triển khai interface `Comparable`, như dưới đây:

```java
public interface Comparable<T> {
    int compareTo(T o);
}
```

Như ta đã thấy trước đó trong lớp, phương thức `compareTo` trả về một số nguyên âm, không, hoặc dương khi đối số thứ nhất nhỏ hơn, bằng, hoặc lớn hơn đối số thứ hai. Nếu tò mò, bạn cũng có thể xem mã nguồn của `Comparable.java` tại [liên kết này](https://github.com/openjdk/jdk/blob/ab66c82ce9fdb5ee3fd7690f42b8ad4d78bf5e40/src/java.base/share/classes/java/lang/Comparable.java#L105).

Sau khi triển khai interface `Comparable`, ta thu được mã như sau:

```java
public class Dog implements Comparable<Dog> {
   ...
   @Override
   public int compareTo(Dog uddaDog) {
       if (size > uddaDog.size) {
           return 1;
       }
       if (size < uddaDog.size) {
           return -1;
       }
       return 0;
   }
}
```

Sau khi triển khai interface này, `Collections.max(dogs)` sẽ hoạt động.

Mặc dù mã ta viết ở trên chạy được, nó hơi vụng về. Một cách làm khác được trình bày dưới đây:

```java
public class Dog implements Comparable<Dog> {
   ...
   @Override
   public int compareTo(Dog uddaDog) {
       return this.size - uddaDog.size;
   }
}
```

Ở đây, ta tiết kiệm vài dòng bằng cách đơn giản là trừ hai kích thước. Trả về hiệu giữa hai số là cách phổ biến để triển khai các phương thức `compareTo` trong Java.

**Dạng** đa hình (*polymorphism*) ta vừa dùng đôi khi được gọi là **đa hình kiểu con** (*subtype polymorphism*).

Ý tưởng ở đây là một kiểu cha (`Comparable`) quy định khả năng (trong trường hợp này là so sánh). Sau đó một kiểu con (`Dog`) ghi đè phương thức trừu tượng của kiểu cha. Khi chạy, Java quyết định phải làm gì dựa trên kiểu thực tế của đối tượng nhận lời gọi phương thức thực thể đó.

## Comparator

Thuật ngữ “thứ tự tự nhiên” (*natural order*) đôi khi dùng để chỉ thứ tự được ngụ ý bởi phương thức `compareTo` của `Comparable`. Trong ví dụ của ta, `compareTo` lấy kích thước làm tiêu chí cho thứ tự tự nhiên của các con chó.

Đôi khi ta muốn xét một thứ tự khác. Ví dụ, ta có thể muốn sắp các con chó theo tên.

Trong Python, ta đạt mục tiêu này bằng cách truyền hàm. Ví dụ, trong đoạn dưới đây, ta truyền `name_len` như một hàm khóa (key) cho `get_the_max`.

```python
def get_the_max(x, key):
  max_value = x[0]
  for item in x:
    if key(item) > key(max_value):
      max_value = item
  return max_value

def name_len(dog):
   return len(dog.name)

max_dog=get_the_max(doglist, name_len)
```

Ngược lại, mã Java thường không dùng truyền hàm để xử lý các thứ tự thay thế. Thay vào đó, ta lại dựa vào **đa hình kiểu con**.

Cụ thể, ta có thể triển khai interface `Comparator`, như dưới đây:

```java
public interface Comparator<T> {
    int compare(T o1, T o2);
}
```

Một ví dụ `Comparator` so sánh các con chó theo tên:

```java
public static class NameComparator implements Comparator<Dog> {
   @Override
   public int compare(Dog a, Dog b) {
       return a.name.compareTo(b.name);
   }
}
```

Để tự kiểm thử hiểu biết, hãy xét bài toán sau. Đầu ra của đoạn mã dưới đây là gì?

```java
Dog a = new Dog("Frank", 1);
Dog b = new Dog("Zeke", 1);
Comparator<Dog> nc = new Dog.NameComparator();
System.out.println(nc.compare(a, b));
```

Đó là một số dương? Số âm? Hay không?

### Dùng một Comparator

Đoạn mã dưới đây minh họa cách ta có thể truyền một `Comparator` vào `Collections.max`.

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Dog maxNameDog = Collections.max(dogs, new Dog.NameComparator());
```

Điều này tương tự cách ta có thể truyền một hàm khóa vào `get_the_max` trong Python.

```python
def length_of_name(dog):
   return len(dog.name)

dogs = [Dog("Grigometh", 10),
        Dog("Pelusa", 5),
        Dog("Clifford", 9000)]
max_dog = get_the_max(dogs, length_of_name)
```

Hãy chú ý sự khác biệt ở đây. Trong Java, ta đóng gói hàm so sánh bên trong một đối tượng `Comparator`, tức là ta dựa vào đa hình kiểu con.

Ngược lại, trong Python, ta truyền một hàm so sánh vào `get_the_max`, tức là ta dựa vào truyền hàm.

### Vài cải tiến nhỏ

Việc tạo `NameComparator` bằng `new` hơi vụng về và (đối với tôi) không đẹp. Có vẻ lạ khi phải khởi tạo một lớp chỉ để truyền một hàm so sánh.

Một cách sửa là thêm một biến `static` trỏ tới một `NameComparator` đã được khởi tạo sẵn. Ta làm điều này trong lớp `Dog`.

```java
public class Dog {
   ...
   public static final Comparator<Dog> NAME_COMPARATOR = new NameComparator();
}
```

Điều này cho phép ta truyền `Dog.NAME_COMPARATOR` vào `Collections.max` mà không phải tạo mới một đối tượng `NameComparator`. Kết quả là mã trông như sau:

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Dog maxNameDog = Collections.max(dogs, Dog.NAME_COMPARATOR);
```

Cách này có thực sự tốt hơn không? Bạn tự quyết!

### Nội dung thêm

Cũng có thể triển khai `Comparator` bằng biểu thức lambda. Ví dụ:

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Comparator<Dog> dc = (a, b) -> a.name.compareTo(b.name);
Dog maxNameDog = Collections.max(dogs, dc);
```

Cách này ngắn gọn hơn một chút, nhưng cũng khó đọc hơn một chút. Trong khóa học này ta không yêu cầu bạn học biểu thức lambda.

## Comparable so với Comparator

Interface `Comparable` quy định rằng tồn tại một “thứ tự tự nhiên”. Các đối tượng thực thể của lớp có thể tự so sánh chúng với các đối tượng khác. Chỉ có một thứ tự như vậy là có thể.
