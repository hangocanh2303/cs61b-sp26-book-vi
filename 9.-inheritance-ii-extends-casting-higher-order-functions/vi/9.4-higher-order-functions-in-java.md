# 9.4 Tóm tắt

### Thứ tự tự nhiên (Python so với Java)

Hôm nay ta đã thấy **đa hình** (polymorphism) và **truyền hàm** (function passing).

Để so sánh hai đối tượng theo một thứ tự nội tại (còn gọi là thứ tự tự nhiên), Python dùng một dạng đa hình gọi là **nạp chồng toán tử**. Java thì dùng đa hình kiểu con.

```python
class Dog:
   def __init__(self, name, size):
       self.name = name
       self.size = size
  
   def __gt__(self, other):
       return self.size > other.size
```

```java
public class Dog implements Comparable<Dog> {
   ...
   @Override
   public int compareTo(Dog uddaDog) {
       return size - other.size;
   }
}
```

Lưu ý: Python dùng *duck typing* (định kiểu “gõ vịt”): không có kiểm tra kiểu tĩnh; không cần khai báo trước là toán tử `>` có được định nghĩa hay không.

### Các thứ tự khác (Python so với Java)

Để so sánh hai đối tượng theo một thứ tự thay thế, Python dùng **truyền hàm**, tức bạn cung cấp một hàm khóa. Ngược lại, Java dùng đa hình kiểu con, giống như với các thứ tự nội tại. Ta đóng gói hàm so sánh trong một đối tượng `Comparator`.

```python
class Dog:
   def __init__(self, name, size):
       self.name = name
       self.size = size

def name_len(dog):
   return len(dog.name)

max_dog=max(doglist, key=name_len)
```

```java
public static class NameComparator 
          implements Comparator<Dog> {
   @Override
   public int compare(Dog a, Dog b) {
       return a.name.compareTo(b.name);
   }
}
```
