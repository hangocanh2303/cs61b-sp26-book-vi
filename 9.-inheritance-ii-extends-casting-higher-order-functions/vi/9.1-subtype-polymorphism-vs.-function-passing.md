# 9.1 Đa hình kiểu con so với truyền hàm

**Nạp chồng toán tử (operator overloading)**

Giả sử ta định nghĩa một lớp `Dog`:

```python
class Dog:
   def __init__(self, name, size):
       self.name = name
       self.size = size
  
   def __gt__(self, other):
       return self.size > other.size
```

Đoạn Python dưới đây có thể dùng để tìm con chó lớn nhất trong một danh sách các con chó.&#x20;

```python
def get_the_max(x):
   max_value = x[0]
   for item in x:
       if item > max_value:
           max_value = item
   return max_value

max_dog = get_the_max(doglist)
```

Hàm `get_the_max` trong Python khá tổng quát và có thể làm việc với mọi kiểu. Nó đạt được tính tổng quát này nhờ khai thác “nạp chồng toán tử”.

Nói rộng hơn, khả năng xử lý nhiều kiểu khác nhau đôi khi được gọi là “đa hình” (*polymorphism*); Wikipedia định nghĩa là “khả năng trong lập trình để trình bày cùng một giao diện lập trình cho các dạng cơ sở khác nhau” \[[wiki](https://en.wikipedia.org/wiki/Polymorphism)]

Trong trường hợp này, toán tử `>` có thể so sánh nhiều kiểu (tức “nhiều dạng cơ sở khác nhau”) trong Python. Còn ý nghĩa cụ thể của `>` do `__gt__` quy định.
