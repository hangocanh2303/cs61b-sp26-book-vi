# 38.1 Các Mô Hình Nén

## So Sánh Các Thuật Toán Nén

Chương trước đã trình bày nhiều phương pháp nén. Điều này đặt ra câu hỏi: với một dòng bit cho trước, thuật toán nào là tốt nhất?

Ví dụ, khi nén văn bản Moby Dick bằng các định dạng khác nhau, `bzip2` cho kết quả tốt nhất.

<figure><img src="../../.gitbook/assets/image (136).png" alt=""><figcaption><p>Các định dạng nén khác nhau áp dụng cho <code>mobydick.txt</code></p></figcaption></figure>

Tuy nhiên, có thể lập luận rằng thuật toán nén tốt nhất cho `mobydick.txt` đơn giản như sau:

<pre><code>D(B):
<strong>    if input == 0:
</strong>        return "Call me Ishamel. ...."
    else:
        return the text as is
</code></pre>

Với hàm giải nén này, ta cô đọng toàn bộ Moby Dick vào một bit duy nhất!

Nhưng có vấn đề. Nếu tính cả code thuật toán giải nén như một phần của mô hình nén (nhớ lại mô hình 2 từ chương trước), Moby Dick không còn được nén thành một bit — mà thực tế đòi hỏi _nhiều_ bit hơn văn bản gốc!

## Thuật Toán Giải Nén

Rốt cuộc, mục tiêu nén là tìm chuỗi bit ngắn tạo ra chuỗi bit dài hơn mong muốn. Phát biểu chính thức:

* Cho chuỗi bit `B`, tìm chuỗi ngắn hơn `DA + C(B)` mà khi đưa vào trình thông dịch sẽ tạo ra `B`. Trong đó `DA` là thuật toán giải nén, `C(B)` là phiên bản nén của `B`.

## Cải Thiện Nén

Nhớ lại ví dụ `HugPlant` từ chương trước. Mã hóa Huffman đạt tỉ lệ nén 25%.&#x20;

Tuy nhiên, với thuật toán tạm gọi là `MysteryX`, ta nén `HugPlant.bmp` xuống còn 29.432 bit — tỉ lệ nén 0,35%! Trong số $$2^{8389594}$$ dòng bit có độ dài $$8.389.594$$, chỉ một trong $$2^{8360151}$$ đạt được tỉ lệ như vậy.

<figure><img src="../../.gitbook/assets/image (157).png" alt=""><figcaption><p>Thuật toán nén bí ẩn vượt trội Huffman với khoảng cách rất lớn.</p></figcaption></figure>

`MysteryX` là gì? Chỉ đơn giản là code Java `HugPlant.java` viết để tạo file `.bmp`! Quay lại mô hình bit tự giải nén, ta thấy sức mạnh của code và trình thông dịch trong nén. Điều này dẫn đến hai câu hỏi:

* **Nén có thể hiểu được (comprehensible compression):** cho dòng bit `B`, ta có thể tạo thuật toán xuất ra code Java đọc được không?
* **Nén tối ưu (optimal compression):** cho dòng bit `B`, ta có thể tìm chương trình _ngắn nhất_ xuất ra dòng bit này không?
