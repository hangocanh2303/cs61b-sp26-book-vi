# 1.1 Chương trình Java đầu tiên của bạn

Chương trình mở đầu kinh điển khi giới thiệu bất kỳ ngôn ngữ mới nào là **Hello World**, tức một chương trình in `Hello World` ra màn hình. Trong Java, **Hello World** có thể được viết như sau:

```java
void main() {
    IO.println("Hello world!");
}
```

Hãy so sánh với phiên bản tương đương trong Python:

```python
print("hello world!")
```

So với sự đơn giản tối đa của Python, ta có thể nhận thấy các đặc điểm sau của chương trình Java đơn giản nhất này:

* Hàm **`main`**: mọi mã được chạy đều phải nằm trong một hàm tên là `main`. Ta sẽ nói về ý nghĩa của `void` sau.
* **Dấu ngoặc nhọn** `{}` dùng để bao các khối mã (hàm, lớp, và các loại mã khác sẽ được nói tới trong các chương sau).
* Mọi câu lệnh đều phải kết thúc bằng **dấu chấm phẩy**.
* Việc in ra màn hình yêu cầu dùng dấu chấm (cú pháp dấu chấm) để truy cập thư viện `IO`, rồi gọi hàm in của thư viện đó.

Để vui một chút, hãy xem [Hello world! trong các ngôn ngữ khác](https://www.rosettacode.org/wiki/Hello_world/Text).
